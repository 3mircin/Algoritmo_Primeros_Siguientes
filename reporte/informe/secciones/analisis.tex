\section{Análisis}

Los conjuntos \textbf{PRIMERO} y \textbf{SIGUIENTE} constituyen estructuras formales
fundamentales en el diseño de analizadores sintácticos predictivos (LL(1)). Su cómputo
correcto a partir de una gramática libre de contexto determina, respectivamente, qué terminal
puede iniciar una derivación (\textbf{PRIMERO}) y qué terminal puede aparecer inmediatamente
a la derecha de un no terminal en alguna forma sentencial (\textbf{SIGUIENTE}).

Para el cálculo de ambos conjuntos se adoptó un enfoque iterativo de \textit{punto fijo}: las
reglas de inferencia se aplican de manera repetida hasta que ningún conjunto varía entre dos
iteraciones consecutivas. Este método garantiza la convergencia para cualquier gramática libre
de contexto finita.

\subsection*{Algoritmo de Primero}

\begin{enumerate}
  \item Si $X$ es un símbolo terminal, entonces $\text{PRIMERO}(X) = \{X\}$.
  \item Si existe la producción $X \to \varepsilon$, se incorpora $\varepsilon$ a
        $\text{PRIMERO}(X)$.
  \item Para cada producción $X \to Y_1\, Y_2\, \cdots\, Y_n$:
  \begin{itemize}
    \item Se incorpora $\text{PRIMERO}(Y_1) - \{\varepsilon\}$ a $\text{PRIMERO}(X)$.
    \item Si $\varepsilon \in \text{PRIMERO}(Y_i)$ para todo $i < k$, se incorpora también
          $\text{PRIMERO}(Y_k) - \{\varepsilon\}$.
    \item Si $\varepsilon \in \text{PRIMERO}(Y_i)$ para todo $i \in \{1,\ldots,n\}$, se
          incorpora $\varepsilon$ a $\text{PRIMERO}(X)$.
  \end{itemize}
\end{enumerate}

\subsection*{Algoritmo de Siguiente}

\begin{enumerate}
  \item Se incorpora $\$$ a $\text{SIGUIENTE}(S)$, donde $S$ denota el símbolo inicial de
        la gramática.
  \item Para cada producción $A \to \alpha\, B\, \beta$:
  \begin{itemize}
    \item Se incorpora $\text{PRIMERO}(\beta) - \{\varepsilon\}$ a $\text{SIGUIENTE}(B)$.
    \item Si $\varepsilon \in \text{PRIMERO}(\beta)$ (o bien $\beta = \varepsilon$), se
          incorpora $\text{SIGUIENTE}(A)$ a $\text{SIGUIENTE}(B)$.
  \end{itemize}
\end{enumerate}

\vspace{0.8cm}

El sistema implementa ambos algoritmos en Python mediante una arquitectura modular organizada
en tres capas: \textit{modelos}, \textit{persistencia} y \textit{presentación}. La capa de
modelos define la clase \texttt{Gramatica}; la capa de persistencia agrupa los módulos de
lectura de archivos y de cómputo de los conjuntos; y la capa de presentación contiene la
interfaz gráfica construida con Tkinter.
